# Dra. Letícia Benício | Estética Avançada & Lipo HD

Landing Page Editorial de Alta Conversão desenvolvida com **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **GSAP (com ScrollTrigger)**, componentes inspirados no **21st.dev** e **Lucide Icons**.

Inspirada na estética editorial *"Dark Studio de Luxo"* e direção visual de alta costura (estilo Lumident e referência Neonix), com tons obsidian/grafite suave (`#09090B`), acentos em ouro champanhe e bronze (`#C5A059`, `#E5C396`), anéis de contorno concêntricos e iluminação de estúdio difusa.

## 🏛️ Estrutura & Dobras da Landing Page

1. **Navbar Ultraelegante:**
   - 100% transparente sobre o Hero e transição fluida via GSAP para vidro escurecido fosco (`backdrop-blur-xl bg-[#09090b]/85 border-b border-[#C5A059]/20`) ao rolar a página.
   - Menu mobile drawer responsivo com animação suave.

2. **Dobra 1: Hero Section (Full-Bleed 100vh):**
   - Fotografia editorial de estúdio com modelo em alta definição e luz de borda quente/bronze.
   - Anéis concêntricos luminosos irradiando atrás do retrato (diretamente da referência visual).
   - Tipografia de grife combinando *Playfair Display* e *Plus Jakarta Sans*.
   - Badges flutuantes: `+1.500 Procedimentos`, `Método EndoFIT`, `5.0 ★ Google Maps`.
   - Botões de conversão tipo pílula com microinterações.
   - **Barra Inferior Editorial:**
     - Botão `CONHEÇA O MÉTODO / PLAY TRAILER` com modal interativo de tecnologia.
     - Cards numerados de insights `01` e `02` com os pilares da clínica.
     - Ícones sociais diretos (`Instagram`, `WhatsApp`, `Google Maps`).

3. **Dobra 2: Por Que Escolher a Clínica (Método EndoFIT):**
   - Arquitetura **Bento Grid** assimétrica com **Spotlight Cards** (cursor tracking radial glow).
   - Detalhamento do método autoral EndoFIT, tecnologia de retração cutânea e suporte pós-operatório assistido.

4. **Dobra 3: Catálogo de Procedimentos e Especialidades:**
   - Abas interativas para navegação instantânea:
     - *Lipoaspiração de Alta Definição (Lipo HD & EndoFIT)*
     - *Tratamento de Flacidez & Retração de Pele*
     - *Remodelamento & Harmonização Glútea (Lipoenxertia)*
     - *Contorno Corporal Completo (Abdominoplastia Estruturada)*
   - Fichas técnicas com tempo de recuperação, indicação clínica, benefícios e CTA direto para WhatsApp.

5. **Dobra 4: Prova Social & Resultados Reais:**
   - Showcase interativo com fotografias reais extraídas da pasta oficial do Google Drive.
   - Carrossel com especificações clínicas de cada caso e nota de conformidade ética médica (CFM).

6. **Dobra 4 (cont.): Depoimentos Reais do Google Maps (5★):**
   - Avaliações autênticas de pacientes (Elizete Zete, Patrícia Freitas, Ronelia Reis, Anne Karolina, etc.).
   - Selo de autoridade com nota 5.0 no Google Maps e link oficial de verificação.

7. **Dobra 5: O Espaço e a Experiência da Paciente:**
   - Galeria fotográfica dos ambientes do prestigiado **Grupo Ana Luíza Duarte** (Palmas - TO): lounge privativo, mesas em travertino, iluminação aconchegante e padrão de biossegurança hospitalar.

8. **Dobra 6: Localização, Horários e Agendamento:**
   - Endereço completo com mapa interativo incorporado em modo escuro.
   - Botão `Como Chegar (Rota GPS Google Maps)` com acionamento direto do aplicativo de navegação.
   - Grade completa de horários de funcionamento (Segunda a Sexta das 08h às 18h, Sábado das 08h às 12h).

9. **Dobra 7: Rodapé Editorial de Luxo:**
   - Logo oficial da Dra. Letícia Benício, links rápidos, dados de atendimento e botão de retorno ao topo.

10. **Conversão Contínua (Floating WhatsApp):**

## 🛠️ Tecnologias Utilizadas

- **Framework:** Next.js 16 (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4 (Design System personalizado com paleta Dark Bronze & Gold)
- **Tipografia:** Google Fonts (`Playfair Display` + `Plus Jakarta Sans`)
- **Animações:** GSAP 3.15 + `@gsap/react` + `ScrollTrigger`
- **Ícones:** Lucide Icons (`lucide-react`)
- **SEO & Structured Data:** Schema.org `MedicalClinic` JSON-LD e OpenGraph completo

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build

# Executar build de produção
npm run start
```
